# 开关课

两节 45 分钟。对象大约五年级。目标是建立直觉：计算机为什么只用开和关，一个数怎么变成电信号，信息怎么存进去。

不讲补码、浮点、字节序、缓存。页面就是课堂上的卡片、开关和彩笔。纸卡片可以留着当没有屏幕时的备份：五张纸，分别画 1、2、4、8、16 个点。

打开：`make run`，浏览器进打印出来的地址。第 2 课用 `/?lesson=2`。

课上反复说的三句：

1. 计算机用可靠的电开关工作。
2. 硬件是身体，软件是指令。
3. 所有信息最终都是位，加上怎么解释它。

页面最下面的 **双向预览** 两节课都留着。翻卡片，Aura 里的 0 和 1 会变。改程序，画面会变。让孩子看到：程序不是另一套魔法，就是这些开关的写法。

## 第 1 课 · 计算机是怎么来的，软硬件，从模拟到数字

**带走的三件事**：计算机大致怎么变小变快；分得清硬件和软件；知道高电压 / 低电压为什么可以当开和关。

| 时间 | 做什么 | 在页面上 |
| --- | --- | --- |
| 0–5 分 | 问：你用电脑或手机做什么？它怎么知道你点了哪里、怎么算数学？ | 先不给答案。引出：它其实只懂开和关。 |
| 5–15 分 | 讲成一条故事，不要年表。算盘和齿轮很慢。电子管像一屋子发热的灯泡，ENIAC 占满房间，还经常坏。晶体管是黄豆大的可靠开关，体积和耗电都降下来。集成电路把成千上万个开关印在一小片硅上。今天的芯片只有指甲盖大，里面有上百亿个开关。 | 第 1 课顶部的五颗珠子，点过去讲。一句收束：越来越可靠的电开关，计算机才能变小、变快、进家门。 |
| 15–25 分 | 硬件是身体。眼睛是键盘、鼠标、摄像头。大脑是 CPU。记忆是内存和硬盘。嘴巴和手是屏幕、扬声器。软件是菜谱，告诉身体先做这个再做那个。游戏是软件，跑在手机这块身体上。没有软件，硬件只是零件。 | 「硬件是身体，软件是菜谱」，以及那四个箭头：你写的字 → 一串指令 → 硬件执行 → 屏幕显示。 |
| 25–35 分 | 模拟像水龙头，0V 到 5V 之间什么值都可能，还会晃，抄一份就不一样。数字像电灯开关，只有高电压（大约 5V，记作 1）和低电压（接近 0V，记作 0）。数字抗干扰，能原样复制，也能用很多开关拼出计算。 | 左边旋钮会晃。右边的灯只有两种，点一下，电压从「约 5V · 开 · 1」变成「约 0V · 关 · 0」。让孩子看下面的程序：`*lamp*` 在 `"1"` 和 `"0"` 之间变。 |
| 35–45 分 | 用几个开关记一个小数字，预告下一课。 | 页底的小卡片。点开、点关，旁边的数会变。按钮进第 2 课可以看一眼，然后收回来。 |

收束再说一遍那三句。留一句：下次我们自己用开关把数字和字母存进去。

关键比喻：晶体管和芯片，就是无数个能极快、极可靠地开合的电灯开关。

## 第 2 课 · 二进制、八进制、十六进制

**带走的三件事**：会用翻倍的卡片数二进制；知道八进制和十六进制是为了把长长的 0/1 读短；明白同一串位可以是数字、字母或像素，看软件怎么解释。

| 时间 | 做什么 | 在页面上 |
| --- | --- | --- |
| 0–5 分 | 复习：计算机只懂开（1）和关（0）。问：那年龄、名字、图片放在哪里？ | 第 2 课。先看五张点卡，默认是 11，二进制 `01011`。 |
| 5–15 分 | 卡片朝上算进去，朝下不算。从右边起每位翻倍，和十进制的「满十进一」对照：这里满二就进一，所以没有数字 2。一起数 0001、0010、0011，直到 1111 是 15。再练年龄或生日是几号。 | 点卡片，或在「十进制」里输入年龄后按回车。日子通常不超过 31，五张卡片够。想只看一个十六进制数字，点「四张卡片」。 |
| 15–25 分 | 二进制一长就难看，所以分组。从右边，每 3 位是一个八进制数字（0–7）。每 4 位是一个十六进制数字（0–9，然后 A=10 … F=15）。一个字节是 8 位。`1111 1111` 写成 `FF`。网页颜色 `#FF0000` 是纯红：红色最大，绿和蓝是 0。 | 分组图就在读法下面。点「一个字节」，再点颜色里的「纯红」「纯绿」「橙色」。也可以自己改红、绿、蓝的两位十六进制。 |
| 25–35 分 | 一个字节可以是一个字母。A 的编号是 65，二进制 `01000001`。同一串位，当数字是 65，当字母是 A，当像素是一排点。计算机并不理解文字，软件决定这些位是什么。 | 「同一串开关，三种意思」。在字母格输入 `A`。汉字会提示：一个汉字要好几个字节，这一课先记英文字母。再往下画 8×8 的点，或盖「笑脸」。 |
| 35–45 分 | 动手，然后收。 | 两件事选一件，或者都做。把名字首字母写成二进制和十六进制。或者改那张小画，看每一行的十六进制。最后看底部的程序，它应该和画面一致。 |

收束：二进制是计算机的母语。八进制和十六进制是人的缩写。信息是位，加上怎么解释它。

关键比喻：十六进制是把一长串「开开关关」收成更短的记号，比如 `A5`。

小作业：把家里某个人的年龄写成二进制，或者找一个网页颜色代码填进颜色格。

如果孩子已经写过一点程序，可以补一句：程序也是一串指令，最后同样变成二进制交给硬件。负数有一种特殊记法，字节还有左右两种排法；这两句点到即可，不要展开。

## 页面和纸卡片的对应

| 纸上 | 页面 |
| --- | --- |
| 五张点卡 16、8、4、2、1 | 「五张点卡」。再大的位不再画点，改写成数字，避免 128 个点。 |
| 举起 = 1，放下 = 0 | 卡片朝上有点，扣过去写着「关」。 |
| 彩笔涂 `#FF0000` | 颜色区的色块和三个通道。 |
| 黑白格子 | 8×8 像素，1 是黑，0 是空。 |

改错了不用怕。程序区按「放弃修改」回到当前画面。关掉页面再打开，会从 `runtime/live.aura` 接着上次的开关。想完全重来，删掉 `runtime/` 再 `make run`。

页面上每改一次，Aura 都在工作区里做一次 replace-value，文本框上面会写出这一笔的编号和节点。那一行是给孩子看的：程序不是另外抄了一份，字是在正在跑的定义上改的。

双向预览里的七个格子，就是这七个字符串节点。翻过卡片之后，定义和字面量的编号还是原来的，变的只有格子里的 0 和 1。点一格，下面的程序会选中对应的那一行。
